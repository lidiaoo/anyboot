# AnyBoot Web 端使用说明

**Web 端不是另一套程序**，它就是 AnyBoot 内置 HTTP 服务托管的那份前端页面 ——
和桌面主窗口是**同一份 `ui/` 代码**（同一份 HTML/CSS/JS，同一个状态快照）。所以：

- 页面上点「重启」「下次启动 Linux」「改端口」，**真的**作用在那台电脑上，不是演示；
- 电脑端界面一改，网页刷新就是新的，不存在两套 UI 走样；
- 装了什么 App 都不用，**一个浏览器就是客户端**。手机浏览器打开同一个地址，效果和 App 一样。

```
┌─────────────┐  http://192.168.0.120:12300  ┌───────────────────────┐
│ 电脑/手机    │ ───────────────────────────▶ │ 电脑 A · AnyBoot      │
│ 的浏览器     │  GET  /           前端页面    │ 内置 HTTP 服务        │
│             │  GET  /api/ui-state  轮询状态 │ 端口默认 12300        │
│             │  POST /api/ui-command 下发命令│ token 鉴权（必填）    │
└─────────────┘                               └───────────────────────┘
```

---

## 一、怎么打开

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| 托盘菜单 | 右键托盘图标 → **远程控制** → **打开 Web 页面** | 最快，不用记 IP |
| 主窗口按钮 | **基本设置 ▸ 远程控制** → **打开 Web 页面** | 主窗口已经开着的时候 |
| 手敲地址 | 浏览器输 `http://<这台电脑的IP>:12300` | 已经知道地址 / 想收藏 |
| 手机 | 手机连**同一个**路由器或热点，浏览器打开上面那个地址 | 躺在沙发上切系统 |

> 端口以「基本设置 ▸ 远程控制」里显示的为准（默认 `12300`）。
> 只有在**应用正在运行**且 HTTP 服务已开启时，这个地址才有响应。

想知道这台电脑的 IP：Windows `ipconfig`，macOS/Linux `ifconfig` 或 `ip addr`，
找 `192.168.x.x` / `10.x.x.x` 那种局域网地址。

## 二、第一次打开要输 token

**token 是什么**：相当于这台电脑的远程控制口令，首次运行自动生成 32 位十六进制。
**去哪看**：AnyBoot 应用 → **基本设置 ▸ 远程控制** → **访问令牌**（那行输入框里）。

首次打开网页会弹出一个框：

1. 把 token 粘进去 → 点 **连接**；
2. token 正确才会存下来（错的 token **不会**记住，免得下次又是一轮失败）；
3. 暂时不想连？点 **暂不连接，先看看界面** —— 进入「预览模式」，能看布局不能操作。
   顶部横幅里随时有 **输入 token** 的入口，不用重新打开页面。

**三个省事小技巧**：

- **带 token 的链接直达**：`http://192.168.0.120:12300/?token=你的token`
  验证通过后 token 会写进 cookie（`anyboot_token`，一年有效），
  之后**同一浏览器**再打开这个地址就不用再输了，地址栏里也不会长期带着 token。
- **输入法会把 token 改掉**：手机软键盘默认首字母大写 / 自动纠错。
  输入框已经关掉了这些开关，若还是不放心，勾上 **「显示 token（确认没被输入法改掉）」** 核对一眼。
- **换 token / 重新连**：顶部横幅连上后会显示 **远程控制已连接**，旁边就有 **更换 token** 按钮。

顶部横幅的三种状态，扫一眼就知道现在是什么情况：

| 横幅文字 | 含义 |
| --- | --- |
| `浏览器预览模式：仅展示界面布局，操作请在 AnyBoot 应用内进行` | 页面不是由 AnyBoot 服务托管的（比如用静态服务器打开 `ui/index.html`），没有后端 |
| `远程控制未连接：请输入访问令牌` | 服务在跑，但还没输 token / token 失效 |
| `远程控制已连接：这里的设置改动实时作用于本机 AnyBoot` | 一切就绪，页面上的操作真的会生效 |

## 三、界面上有什么

页面分两个栏目，**左上角页签**切换：

### 系统引导（主功能）

- **rEFInd 下次启动**：点一下 `Linux` / `Windows` / `macOS`，改写 `PreviousBoot`，
  下次开机会进所选系统（当前这次不受影响）。
- **GRUB 列表**：同一页下方展示 GRUB 条目（树形 / 列表两种展示方式，按需切换）。
- 顶部有一行大字写明「下次启动的是哪个系统」，选中项带绿色对勾。

### 基本设置

- **应用设置**：主题（暗色 / 亮色 / 跟随系统）、窗口不透明度、开机启动、扫描等。
- **远程控制**：HTTP 服务开关、监听地址、端口、访问令牌、**打开 Web 页面**、
  通知弹窗与延迟执行（HTTP / CLI 两条渠道分开配）。
  端口被别的程序占用时，这里会直接写出占用者的 PID + 进程名，并给出
  「结束占用进程」「重试监听」两个按钮。

改动是**实时**的：网页上改完，那台电脑的托盘菜单和主窗口会跟着一起变
（网页每 2 秒拉一次 `/api/ui-state` 快照，页面在后台时自动跳过，不白耗电）。

## 四、导航地址（刷新 / 收藏 / 分享都落回同一个栏目）

栏目写进了地址栏的 hash，所以刷新不会跳栏目：

| 地址 | 栏目 |
| --- | --- |
| `http://192.168.0.120:12300/#/boot` | 系统引导 |
| `http://192.168.0.120:12300/#/settings` | 基本设置 |

- **刷新停在原地**：正在「系统引导」就刷新「系统引导」；在「基本设置」就刷新「基本设置」。
- **可以收藏**：把 `#/settings` 存成书签，一点就进基本设置。
- **可以分享**：把带 `#/boot` 的链接发给别人（注意链接里**别带 token**）。
- 打开时**没带 hash**（比如手敲 IP 直接回车、或从手机 App 里打开）→ 固定进 **系统引导**，
  不会记住上次停在哪个栏目，免得每次打开都掉进基本设置。
- 切栏目用的是替换历史记录（不是新压一条），所以来回点不会把浏览器后退塞满。

## 五、Web 端做不了什么

网页是浏览器沙箱，有些操作天生做不了。这类命令在服务端就被**显式拒绝**，
页面会明确告诉你「该操作需要在电脑上完成」，而不是默默失败：

- 弹出**文件夹选择框**（选 ESP 挂载点、选自定义音频等）；
- 打开系统设置页 / 系统级对话框；
- 需要提权弹框（`pkexec`）的写 ESP、写 `grub.cfg` 等 —— **远程请求不会弹框**，
  所以这类操作请在电脑上做，或者用下面的方式在电脑上完成。

`/api/status`、`/api/requests`、`/api/grub`、`/api/ui-state`、`/api/ui-command` 这些
纯读写命令**都能**在网页上用。

## 六、手机浏览器

不用装 App 也能用：手机连同一局域网，浏览器打开 `http://<电脑IP>:12300` 即可，
页面本身做了窄屏响应式适配（分栏自动堆叠）。区别只有三点：

- 手机浏览器**没有标签栏**，一个页面只能连一台电脑；要一台手机同时连多台电脑、还能分组，
  用 `../mobile/` 里的 Android / iOS 客户端。
- 手机软键盘可能改动 token，用上面那个「显示 token」核对；
- 建议在手机上勾选「添加到主屏幕」，下次一键直达。

## 七、常见问题

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 浏览器打不开，转圈或超时 | ① 电脑上 AnyBoot 是否在运行、**远程控制**里 HTTP 服务是否已开启；② 手机/另一台电脑和这台是否**同一网段**；③ 系统防火墙是否放行了该端口（三端各自的防火墙处理见根 README） |
| 提示「远程控制未连接」/ 反复要 token | token 输错或已被改过 —— 到 **基本设置 ▸ 远程控制 ▸ 访问令牌** 核对；用 `/?token=xxx` 直达最稳 |
| 提示端口被占用 | 界面会写明占用者的 PID + 进程名，点「结束占用进程」或「重试监听」，也可换端口（如 `12400`） |
| 页面只能看不能点 | 处于**预览模式**（顶部横幅会写明）—— 说明页面不是由 AnyBoot 服务托管的，换用上面的地址打开 |
| 改了设置没生效 | 看顶部横幅是否「远程控制已连接」；未连接时改动只停在本地，不会下发 |
| 手机输 token 总是不对 | 勾「显示 token」核对，注意别把空格/换行粘进去，也别被输入法首字母大写改掉 |

## 八、安全提醒

- 服务是**明文 HTTP**，**只适合可信局域网**；不要把 `12300` 直接映射到公网
  （要公网用就套一层 HTTPS 反代或 VPN / 隧道，并把 `httpBind` 收成 `127.0.0.1`）。
- token 就是这台电脑的远程控制口令：谁能拿到，谁就能切系统、重启、关机。
  泄漏了就在 **基本设置 ▸ 远程控制** 里换一个（保存后监听立刻按新 token 重启）。
- 服务端**不允许无鉴权监听**：`httpToken` 为空时 HTTP 服务直接拒绝启动。
