操作说明

  • 电源指令以标准 Wake-on-LAN 魔术包 发送（开机 UDP 9 / 睡眠 10 / 关机 11 / 重启 12），目标机离线也能开机。
  • 关机与重启 立即执行，不会二次确认。
  • rEFInd / GRUB 的选择写入该机引导配置，下次重启时生效，可点「撤销」恢复原值。
  • 设备离线时引导项不可改；离线设备只有「开机」可用，其余置灰。
  • 显示「未检测到」= 该机没部署对应引导管理器。

连接 AnyBoot 服务端

换行 / 空格 / 逗号 / 分号都能分开；认不出的文字（备注、括号）自动忽略

没写端口按 12300 补。地址已存在时只把 MAC 追加进去（可以拿它给已有地址补网卡）； 点 MAC 标签可以单独删掉那块网卡。MAC 只用于局域网电源，不影响连接。

经跳板机中转的连接方式将在后续版本启用，当前先保存档案

并发（首个）：每个地址一个线程，任一响应立即用它，其余作废； 并发（全部）：等全部探完，逐行报每个地址的成败与耗时；串行：按顺序试，第一个通就停。

配了路由，电源按钮就往局域网发 UDP 包，由这台电脑上的 sol 按端口执行对应动作 —— 机器睡着、连接断着也能用；没配则唤醒走标准 WOL。 广播地址留空 = 自动（全局广播 + 各地址的 /24 广播）；MAC 全不勾 = 用上面地址里配过的全部网卡。

添加服务器

协议
换行 / 空格 / 逗号 / 分号都能分开；认不出的文字（备注、括号）自动忽略

没写端口按协议默认（SSH 22 / Telnet 23）。地址已存在时只把 MAC 追加进去（可以拿它给已有地址补网卡）； 点 MAC 标签可以单独删掉那块网卡。MAC 是局域网电源的必填项（包体就是魔术包），不影响连接。

认证方式

「交互」= 系统 ssh 在终端内要密码 / 确认指纹，凭据不落盘；「密码」= 密文落盘（AES-256-GCM），ssh 经 askpass 免输，指纹确认仍在终端里；「密钥」= 起 ssh 带 -i（带口令的钥匙仍在终端里解锁一次）。三种方式互斥，切换即清掉另一种存的凭据。
