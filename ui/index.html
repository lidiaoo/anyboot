GRUB 启动项

还没识别到 GRUB 启动信息 选 ESP 分区里的文件夹去识别，或直接填上面的 fs-uuid —— 两种方式填一个就行，另一个会自动对上
引导配置须知
  • Linux 必须开启 os-prober：在 /etc/default/grub 里加 GRUB_DISABLE_OS_PROBER=false 后执行 update-grub，其他系统的启动项才会进 grub.cfg； 装了多个 Linux 发行版时，只需让一个发行版管理 EFI（它的 GRUB + os-prober 收集其余系统）。
  • Windows 的 EFI 分区，GPT 标志必须是 boot, efi（gparted 里给该分区设 boot 标志）， 否则 os-prober 不识别它。
  • EFI 第一启动项：用 rEFInd 就把 rEFInd 的 EFI 设为第一启动项； 不用 rEFInd 就把 GRUB 的 EFI 设为第一启动项。
把当前系统 /boot/grub/grub.cfg 同步到 ESP（需已挂载到 /boot 或 /boot/efi）

          安装 = 下载 → 清空安装目录 → 解压到安装目录 → 官方 install.sh（静默 = 无人值守自动确认；手动 = 呼出终端由你回答脚本问句）。解压前会清空安装目录，但保留 sol.yaml 配置文件（端口、token 等设置不丢）；包内容直接铺在安装目录下，不保留 sol-v* 子目录。配置 sol.yaml 就在安装目录里；卸载保留它以便回滚。
