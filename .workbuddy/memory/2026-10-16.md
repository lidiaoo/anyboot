## 第四十一轮：终端「输入字立马消失」修复（监听器挂死 Activity）
- 用户实机反馈：回显能出来后，输入的字闪一下就没了。根因：TerminalSession 的 Listener 在构造时捕获且不可换，而会话设计为「Activity 销毁不关会话」——终端页退出再重进（或 Activity 重建）后，新实例 bind 拿到积攒回显（横幅/提示符正常），但实时回显仍派发给已销毁旧 Activity 的 listener → runOnUiThread 到死实例 → onDestroy 已把 terminalView 置 null → evaluateJavascript 静默落空，回显全丢；输入法组词预览闪一下即清 = 「输入字立马消失」。
- 修复三处（TerminalSession.java / TerminalActivity.kt / assets/terminal/index.html）：
  1. TerminalSession.listener 去 final + setListener()（dataLock 保护）；bind() 重挂 listenerFor(当前 Activity)——主修。
  2. deliver() 改为只在未挂界面时写 backlog：挂着时 backlog 不积累，修掉 onResume 同会话 attachAndDrain 把整屏历史重印一遍的重复回显。
  3. index.html term.onData 去掉 window.__ready 门槛（term 已建即转发；未连上时原生 write 对 output==null/closed 安全 no-op），防任何 __ready 异常态静默吞输入。
- 重打包 md5 b558f25d（AnyBoot-remote-v1.2-compose-debug.apk）。
