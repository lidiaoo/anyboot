
## GRUB 自动读取：grubenv 写入链落地（三档成熟度）
- 用户定案三点：① 写入目标一律「该分区下的 /boot/grub/grubenv」（兼容 grub/grub2，scan 按实际目录记 rel），不落本机语义；② 要讲清风险、用成熟做法；③ 必须提权。
- 实现：runtime_from host 判定 part.dev=="本机"（原按 platform 判恒 true 的 bug）；write_env 本机直写分支收进 cfg(not(linux))，Linux 本机行落穿公共提权段；write_env_block Linux 三档：本机绝对路径文件写（root）→ 已挂载走挂载点文件写（/proc/self/mounts 认 ext 家族+rw，坚持不裸写已挂载分区——绕过页缓存会被脏页回写盖掉）→ 未挂载裸设备 O_RDWR + overwrite_in_place（grub-editenv 同语义：inode→extent 定位自身数据块、整块读改写、回读比对、RECOVER 拒写、不动元数据）。ext4_raw 补 Linux open_raw_rw。
- 提权链不动：--linux-grub-write 子命令（main.rs ⓪.56 root 硬校验）经 spawn_privileged 三通道（免密助手→pkexec→密码）。
- 测试 +3（host 判定、mounts 解析含 \040、原地覆盖四道闸），506 全绿。构建留用户自己出。
