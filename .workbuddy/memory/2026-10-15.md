## macOS「每次都要输密码」追查（用户报：主窗口/托盘点重启每次弹密码）
- 代码事实（tauri 2.12.2 `process.rs:74`）：`app.restart()` → macOS 走
  `restart_macos_app` = `/usr/bin/open -n <bundle> --args ...`（LaunchServices 接管），
  **零提权**；`restart_app` 只有 stop_http_server + app.restart()，没有任何 osascript/sudo。
- 实测本机：`pgrep`/`lsof` 显示跑着的是 PID 6862 `/Applications/AnyBoot.app/...`，
  **属主 jianghh（非 root）**；bundle 无 quarantine 属性，ad-hoc 签名（spctl rejected
  但没 quarantine 就不会被 Gatekeeper 拦）。所以「重启程序」理论上不该弹密码。
- macOS 唯一会弹管理员框的地方 = 电源动作：`power_attempts()`（lib.rs:10925）macOS 分支
  Reboot/Shutdown 都是 `osascript -e 'do shell script "/sbin/shutdown -r now" with
  administrator privileges'`（needs_gui_auth=true）→ **每次必弹**，Authorization Services
  没有「记住本次授权」。托盘电源区标签是「重启系统/关机/睡眠」（`PowerAction::label`），
  托盘**没有**「重启程序」这一项。
- 顺带挖到的既有问题：`run_power_action` 里 `next_power_step(&outcome,
  escalation.is_some())`，而 macOS 的 `escalate_power` **恒返回 None** → Failed 一律走
  Stop，**候选表里第二条以后永远不会被执行**。也就是说 macOS 睡眠那三条候选
  （System Events → `sudo -n pmset` → osascript 管理员框）实际只有第一条会跑，
  README「配了免密 sudo 就能免密睡眠/重启」在 macOS 上根本没生效。
- 结论/候选方案（未改代码）：①sudoers 免密 `jianghh ALL=(ALL) NOPASSWD: /sbin/shutdown,
  /usr/bin/pmset` + macOS Reboot/Shutdown 前置 `sudo -n /sbin/shutdown -r now` 候选，
  并把 `sudo -n` 的「需要密码」失败归为 Next 而非 Stop（否则一失败就断链）；
  论点：苹果菜单「重新启动」本来就不需要密码，放开 /sbin/shutdown 不降低实际安全等级。
- **用户确认「点重启系统时弹密码」+ 选「要，改」→ 已实现（lib.rs，125 单测全过）**：
  - 新增 `PowerAttemptOutcome::Unavailable`（「这条候选在本机用不了」）→ `next_power_step`
    归 Next（与 Missing 同类）；`describe()` 合并进 reason 分支。
  - 新增纯函数 `sudo_without_password(program, args, stderr)`：只认 `sudo` + 带 `-n` +
    stderr 命中 "a password is required"/"no tty present"/"a terminal is required" →
    `run_power_command` 判为 Unavailable（**没带 -n 的 sudo 不算**，那可能真弹了框）。
  - macOS 候选表：Reboot/Shutdown 各加前置 `sudo -n /sbin/shutdown -r|-h now`
    （helper `sudo_nopasswd()`），osascript 管理员框降为兜底；Sleep 的 `sudo -n pmset`
    改用同一 helper。
  - 测试：`macos_power_table_uses_administrator_privileges` → 改名
    `macos_power_table_prefers_nopasswd_sudo_over_the_admin_prompt`（断言 len=2、
    `command()=="sudo -n /sbin/shutdown -r now"`、needs_gui_auth=false）；新增
    `sudo_without_password_is_a_missing_candidate_not_a_refusal`；
    链路测试补 Unavailable→Next 断言。
  - 文档：README §电源动作命令表 + §远程需要本机授权（macOS 免密 sudo 段）+
    docs/remote-api-plan.md 命令表（附「换人规则」引文）。
  - 产物：`npx tauri build --target universal-apple-darwin --bundles app`（**只出 .app，
    不打包 DMG，可全程沙箱**）→ src-tauri/target/universal-apple-darwin/release/bundle/macos/
    AnyBoot.app，lipo=x86_64 arm64、adhoc 签名、25M、二进制 md5 a7671bfd。
