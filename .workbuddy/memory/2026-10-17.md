**文件页十四项功能（第四十九轮）+ 两个真 bug 修复**

- **SftpOps.copyTree 截断 bug（已修）**：同一条 sftp 通道上一边 `get()` 拿读流一边 `put()` 拿写流会**死锁**——只写出一个数据包（2 MiB 源只落 32,755 B），之后 `read()` 永不返回。JVM 对照探针 `~/.cache/ab-droid/SftpCopyProbe.java` 四组对照（A 同通道交织 ⏱死锁 / B 本地临时文件 ✅10.4s / C **两条通道 ✅5.3s** / D 先全读进内存 ✅10.4s）。修法：`SftpOps` 加 `withTwo()`（reader/writer 两条通道），`copy`/`move` 的退化路径都走 `copyTree(reader, writer, …)`。C 又对又快一倍还不占本地磁盘。
- **「远程控制 token 弹窗关不掉」bug（已修，用户报的）**：`ui/styles.css` 的 `.token-modal-overlay` 设了 `display:flex`，作者样式永远压过 `[hidden]` 的 UA 样式 → JS 里 `overlay.hidden = true` 只是改属性，**弹窗永远盖在屏幕上**：连接成功不消失、点「暂不连接」也无视觉反应（状态其实都生效了：`remoteToken` 正确、WS 已连上、cookie 已写）。整个页面被 z-index:100 的遮罩锁死。修法一行：`.token-modal-overlay[hidden]{display:none}`（仓库里 `.tab-panel`、`.grub-empty-state` 早就为同一个坑补过，就它漏了）。教训落 `MEMORY-detail-desktop.md`。
- **调试方法（可复用）**：手机 WebView 里 `uiautomator dump` 看不到网页内容 → 走 **CDP**：`adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>`，再用 `~/.cache/ab-droid/cdp.py eval "<js>"` 直读页面变量（`remoteToken`/`tokenModal.overlay.hidden`/computed display）。注意 websocket-client 要 `suppress_origin=True`（403）；node 的 undici fetch 会撞 WASM 内存墙（ulimit 4G），用 python。

## docs/client-ui 设计稿全套代码还原 · PC 线（第五十一轮）

- **用户需求澄清**：`docs/client-ui/` 下整套设计稿一比一实现 + 真功能（不止 hub 一张）。经确认本轮范围 = PC 线全部（② 终端窗 → ③ 隧道已有 → ④ SFTP → 密钥管理），手机端 7 屏（mobile-redesign-all.html）待后续轮。
- **新增后端模块**：
  - `hub_keys.rs`：密钥 CRUD 全借系统 ssh-keygen（生成 -t ed25519/rsa、指纹 -lf、口令判定 `-y -P ""` 成败）；私钥只落 config_dir/keys/，接口永不回私钥体；used_by = hub-servers.json 里 key_id 引用数；删除时被引用则拒绝。
  - `hub_sftp.rs`：全部走系统 `sftp -b -`（stdin 批命令）+ BatchMode + ControlPath 复用 ControlMaster（与隧道同款）；list 解析 `ls -la`（LC_ALL=C）；download 用 dialog 存盘 + 300ms 轮询本地文件大小发 `hub-sftp-progress`；upload 走 dialog 多选，进度不确定态。
- **HubServer 加 `key_id` 字段**（serde default 向后兼容）：空 = 交互认证；非空 = 起 ssh 带 `-i` + `IdentitiesOnly=yes`（带口令钥匙由 ssh 在 PTY 里交互解锁）。
- **hub_term.rs 改造**：TermSession 记 `window`（事件 emit_to 承载窗，不再发 hub 窗）；`kill_window` 按窗收会话；hub 窗销毁**不再** kill_all（会话已归 server-term 窗）；最后会话结束自动关窗（前端无 close 权限）；`hub_term_take_pending` / `hub_term_sessions`（页面刷新重建标签）。
- **窗口接线**：三个新窗 label `server-term` / `server-files` / `server-keys`（hub_term.rs/hub_sftp.rs 各有 open_*_window：存在即聚焦+emit 事件换服务器，新开则 pending 队列）；capabilities windows 已加三个 label；应用退出统一 kill_all。
- **前端**：`ui/hub-term.html`（标签条+xterm+状态栏+延迟=每 10s TCP 实测）、`ui/hub-files.html`（面包屑/表格/传输行/时钟）、`ui/hub-keys.html`（生成/导入/删除/复制公钥/口令警告/被 N 台使用）；hub.html 删内嵌终端，三按钮全改开窗，编辑弹窗加「认证方式」分段（交互/密钥+选钥匙）。
- **⚠️ 踩坑（本轮沉淀）**：
  1. **paramiko 系 `ls -la` 日期是「日 月 时」序**（`17 Oct 01:46`），GNU 是「月 日 时」——解析器两种都得认，否则整表静默变空。
  2. **老版 OpenSSH sftp 不认 `pwd -P`**，用裸 `pwd`。
  3. **Tauri async 命令在 private mod 里 generate_handler 报 "macro import is private"** → async 命令必须 `pub`、模块 `pub(crate)`；sync 命令没这问题。
  4. **lib.rs 里定义的 tauri 命令要 `fn` 不要 `pub fn`**（pub 会和 generate_handler 的宏 re-export 撞 E0255）——与既有代码风格一致即可。
  5. `if let Ok(x) = state.field.lock()` 配 `State<'_>` 借用报 E0597（Result 临时值析构晚于 state）→ 用 `match` + **语句带分号**。
  6. 本机 `/tmp` 在多条 Bash 命令间不共享（命名空间），跨命令文件一律放 `~/.cache/ab-droid/`。
  7. ab_sftp_fixture（paramiko 靶机）**每条新连接重置根目录**——跨连接的远端改动会丢，演练要放同一连接内。
- **验证**：156 单测全过；release 构建通过；sftp 批命令对真靶机全演练（mkdir/put 带空格文件名/rename/rm/rmdir/get 2MiB md5 一致，退出码 0）；四个页面内联 JS node --check 全过。**窗口 UI 未实机跑**（运行中的 PC 实例是旧二进制，等用户重启）。
