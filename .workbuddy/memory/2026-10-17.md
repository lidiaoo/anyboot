**文件页十四项功能（第四十九轮）+ 两个真 bug 修复**

- **SftpOps.copyTree 截断 bug（已修）**：同一条 sftp 通道上一边 `get()` 拿读流一边 `put()` 拿写流会**死锁**——只写出一个数据包（2 MiB 源只落 32,755 B），之后 `read()` 永不返回。JVM 对照探针 `~/.cache/ab-droid/SftpCopyProbe.java` 四组对照（A 同通道交织 ⏱死锁 / B 本地临时文件 ✅10.4s / C **两条通道 ✅5.3s** / D 先全读进内存 ✅10.4s）。修法：`SftpOps` 加 `withTwo()`（reader/writer 两条通道），`copy`/`move` 的退化路径都走 `copyTree(reader, writer, …)`。C 又对又快一倍还不占本地磁盘。
- **「远程控制 token 弹窗关不掉」bug（已修，用户报的）**：`ui/styles.css` 的 `.token-modal-overlay` 设了 `display:flex`，作者样式永远压过 `[hidden]` 的 UA 样式 → JS 里 `overlay.hidden = true` 只是改属性，**弹窗永远盖在屏幕上**：连接成功不消失、点「暂不连接」也无视觉反应（状态其实都生效了：`remoteToken` 正确、WS 已连上、cookie 已写）。整个页面被 z-index:100 的遮罩锁死。修法一行：`.token-modal-overlay[hidden]{display:none}`（仓库里 `.tab-panel`、`.grub-empty-state` 早就为同一个坑补过，就它漏了）。教训落 `MEMORY-detail-desktop.md`。
- **调试方法（可复用）**：手机 WebView 里 `uiautomator dump` 看不到网页内容 → 走 **CDP**：`adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>`，再用 `~/.cache/ab-droid/cdp.py eval "<js>"` 直读页面变量（`remoteToken`/`tokenModal.overlay.hidden`/computed display）。注意 websocket-client 要 `suppress_origin=True`（403）；node 的 undici fetch 会撞 WASM 内存墙（ulimit 4G），用 python。
- **判错链路**：PC 端 `/api/requests`（带 token curl）能看到每个请求的来源 IP/路径/rejected 原因——用户真机 192.168.0.248 的 401/成功时间线就是它给的；模拟器走隧道出口，来源显示 127.0.0.1。
- **PC 端 UI 是 `include_str!` 编译期嵌入**（lib.rs `UI_STYLES_CSS` 等）：改 `ui/*` 必须重编。已交付两份：裸二进制 `target/release/anyboot`（**zig 重链版**，md5 `afb152d762cda6224b4dfc6a2aeaa452`，门槛 GLIBC_2.34，strings 可搜到修复）+ 自包含包 `bundle/appimage/AnyBoot_0.1.0_amd64-jammy.AppImage`（02:47，94,300,664 B，全包门槛 2.35、自检 A/B 全过；jammy 打包脚本会先用 zig 重链本体——zig 0.13.0 已安置在 `~/.cache/ab-zig/zig/zig` 供脚本回退）。⚠️ 重启得用户做：运行中的实例在沙箱外的命名空间，我杀不到；且托盘「重启程序」会重启**旧二进制**，必须退出后从新二进制/AppImage 启动才生效。另注意后台 cargo 会静默卡死（1 小时零写入、target 无任何 mtime 变化即判卡，停掉重跑 30 秒就完成——大头其实早编完了）。

## server-hub 窗口按设计稿重构（第五十轮）

- **用户要求**：把 `docs/client-ui/pc-hub-redesign.html` 设计稿做代码实现。实现目标 = `ui/hub.html`（`frontendDist: "../ui"`，直接从 ui/ 目录供资产；build.rs 是裸 `tauri_build::build()`，**ui/*.html 不走 codegen 链**，可放心整写）。
- **做法**：整文件重写（vanilla CSS 双主题 token，不用 Tailwind CDN——离线窗口没网），**保留全部既有接线**：hub_list/save/delete/test_server、hub_term_*（xterm 多标签）、hub_*_tunnel、事件监听、Esc/Enter 快捷键。
- **设计→现实的映射取舍**（不做假数据）：
  - 自绘标题栏（min/max/close）→ 跳过：hub 窗口是系统标题栏（lib.rs `open_hub_window` 无 decorations(false)）。
  - 心跳/在线状态 → 用「测试连接」结果（probes：state+ms+hist），工具栏汇总「N 在线 / M 离线」。
  - 延迟趋势 sparkline → 真实现：前端测 `hub_test_server` invoke 耗时（TCP 握手代理），会话内存 60 次，≥2 次出图 + p95。
  - TOFU 指纹 / 跳板机 / 密钥库 / 「浏览文件」→ 后端没有，跳过或灰掉（disabled + title 说明）。
  - 认证方式格子 → 写实「系统 ssh · 终端内交互」（hub.rs 的设计如此，密码不落盘）。
- 新增小件：Toast（替代 alert）、底部状态栏时钟、协议分段带实时计数、列表「刷新」= 批量重测全部、编辑弹窗内「测试连接」带 ms。
- ⚠️ **生效条件**：release 包里 frontendDist 资产是编译期嵌进二进制的，改 ui/hub.html 后要重编 cargo 才进已安装的包；dev 模式即时生效。
- 提交：hub 线单独提交（只 ui/hub.html），不与移动端混。
