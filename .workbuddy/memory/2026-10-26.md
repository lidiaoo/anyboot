## mac 上编 PC（Tauri）+ Android 的可用配方

本机是 **Hackintosh：AMD Ryzen 7 5700X、macOS x86_64、无 arm64**（`uname -m` = x86_64，
`hw.optional.arm64` 不存在）→ 只能出 x86_64 版；Windows 版仍需 Windows 机（无 MSVC）。

**PC**：`npm run build:mac-intel`（package.json 里已带 `env -u CARGO PATH=$HOME/.cargo/bin:...`
+ clang AR，别自己拼 cargo 命令）。约 1.5 分钟。产物：
- `src-tauri/target/x86_64-apple-darwin/release/anyboot`
- `bundle/macos/AnyBoot.app`（ad-hoc 签名 `-`，`codesign -v` 通过，64M）
- **dmg 这一步在本机会失败**：`bundle_dmg.sh` 要挂载 + AppleScript 让 Finder 摆窗口布局，
  无 GUI 自动化许可时报 `failed to run bundle_dmg.sh`（前面 hdiutil create 是成功的）。
  清场：`hdiutil info` 找残留挂载点（名字是随机 `dmg.xxxxxx`）→ `hdiutil detach -force` →
  删 `macos/rw.*.dmg`；补包：`hdiutil create -volname AnyBoot -srcfolder macos/AnyBoot.app
  -ov -format UDZO dmg/AnyBoot_0.1.0_x64.dmg`（无背景图/布局，能装）。

**前端是否真的进了二进制**（`frontendDist: "../ui"`，Tauri 2 codegen 会 brotli 压缩，
中文搜不到别急着报「没更新」）：看
`target/<triple>/release/build/anyboot-*/out/tauri-codegen-assets/` 里哪个文件 mtime 是新的，
再用 node 的 `zlib.brotliDecompressSync` 解压搜自己的新函数名——比 `strings` 靠谱。

**Android**：无 `gradlew`、无全局 gradle，直接用已下载的 wrapper 发行版：
`~/.gradle/wrapper/dists/gradle-8.14.3-bin/<hash>/gradle-8.14.3/bin/gradle`（AGP 8.7.3 要 Gradle 8.9+）。
必须显式给 JDK17 + SDK + **覆盖 user.home**：
```
env JAVA_HOME=/usr/local/software/jdk/jdk-17 \
    ANDROID_HOME=$HOME/Library/Android/sdk GRADLE_USER_HOME=$HOME/.gradle \
    gradle '-Dorg.gradle.jvmargs=-Xmx2048m -XX:MaxMetaspaceSize=512m -Dfile.encoding=UTF-8 -Duser.home=/Users/jianghh' \
    :app:assembleDebug
```
`gradle.properties` 里写死了 `-Duser.home=/home/jianghh`（Linux 机器），不覆盖的话
debug keystore / `.android` 会去找不存在的目录。产物 `app/build/outputs/apk/debug/app-debug.apk`。

**APK 内容核对**：类不止在 classes.dex（本工程 4 个 dex，`RemotePair` 在 **classes3.dex**），
逐个 dex `unzip -p … | strings | grep` 才搜得到；别用体积当判据。

## 替换 /Applications/AnyBoot.app（新 S4/S5 版）

- `osascript -e 'quit app "AnyBoot"'` 在本会话**被拒**（`-10004 权限违例`，没有 Apple Events 授权）
  → 直接 `kill -TERM <主进程PID>`：主进程与 tsnet 子进程正常退出，**cloudflared 会成孤儿**（要单独 kill）。
  端口 12300 随后释放。
- 流程：备份旧 `.app`（`ditto` → `.workbuddy/artifacts/`，86M）→ `ditto` 新 `.app` 到 `/Applications/AnyBoot.new`
  → `codesign -v` 通过 → `mv` 交换 → `md5` 与构建产物一致（`166500cf…`）→ `open` 启动 → `/health` ok。
- `/Applications/AnyBoot.old` 用 `/usr/bin/trash` 移入回收站（`~/.Trash/AnyBoot.old`），别留两份 86M。
- 本机 `settings.json` **没有 `remote_servers` 键**（这台 mac 从没配过远端档案）→ 无旧字段迁移风险。
- trace.log 里的 `[ui-error] [render]` 是既有噪声（历史 561 次），本次启动 `[js]` 未捕获错误为 0。
