本机是 **Hackintosh：AMD Ryzen 7 5700X、macOS x86_64、无 arm64**（`uname -m` = x86_64，
`hw.optional.arm64` 不存在）→ 只能出 x86_64 版；Windows 版仍需 Windows 机（无 MSVC）。

**PC**：`npm run build:mac-intel`（package.json 里已带 `env -u CARGO PATH=$HOME/.cargo/bin:...`

  无 GUI 自动化许可时报 `failed to run bundle_dmg.sh`（前面 hdiutil create 是成功的）。
  清场：`hdiutil info` 找残留挂载点（名字是随机 `dmg.xxxxxx`）→ `hdiutil detach -force` →
  删 `macos/rw.*.dmg`；补包：`hdiutil create -volname AnyBoot -srcfolder macos/AnyBoot.app
  -ov -format UDZO dmg/AnyBoot_0.1.0_x64.dmg`（无背景图/布局，能装）。

**前端是否真的进了二进制**（`frontendDist: "../ui"`，Tauri 2 codegen 会 brotli 压缩，
中文搜不到别急着报「没更新」）：看
`target/<triple>/release/build/anyboot-*/out/tauri-codegen-assets/` 里哪个文件 mtime 是新的，
再用 node 的 `zlib.brotliDecompressSync` 解压搜自己的新函数名——比 `strings` 靠谱。

`~/.gradle/wrapper/dists/gradle-8.14.3-bin/<hash>/gradle-8.14.3/bin/gradle`（AGP 8.7.3 要 Gradle 8.9+）。

    gradle '-Dorg.gradle.jvmargs=-Xmx2048m -XX:MaxMetaspaceSize=512m -Dfile.encoding=UTF-8 -Duser.home=/Users/jianghh' \

## 手机界面崩坏排查（commit 3231940，真机 96b199d）

**先纠正一个长期误解**：手机主界面不是原生 Compose，是 **WebView 加载电脑端的
`ui/index.html`**。所以「页签折行 / 橙色横幅错乱 / 底部状态条三行」全都得改 PC 前端
（`ui/styles.css` + `ui/app.js`），改完重编 App 才会生效。只有电脑列表、编辑表单、
抽屉是 Compose。

**视口 354px 是这次的关键数字**：真机 1240px / 3.5 密度 = 354 CSS px，AVD 是 1080/2.625
= 411px —— 411 下刚好放得下的三个页签，354 下就折成「系统引 / 导」。过去只在模拟器上看
所以没发现。720px 断点管不到这么窄，新加 **480px 断点**（只补四条：页签平分 nowrap、
横幅 flex 换行、状态条 line-clamp 2、系统卡片按钮整行铺开）。

**Compose 侧的通用病灶：M3 `TextButton` 有 58dp 最小宽度**。配对行一行三个（↑↓✕）
= 174dp，354dp 屏上地址框只剩 78dp，实测只显示「https」四个字母，地址既看不见也改不了。
解法是自绘 `TinyTextButton`（30dp、无底色），顺带干掉按压态的紫色胶囊残留。同样
58dp 也把通道优先级行的名称挤到折行（「Tailscale Funnel（内建）」）。

**「⏻」(U+23FB) 在 Android 上没有字形** → 主界面悬浮球是个空白紫圆。凡是把 Unicode
符号当图标用都要在真机核一遍；项目 `Icons.kt` 里已有自绘 PowerIcon/CloseIcon。

**验排版的方法**（mac 无 CDP、模拟器太慢）：把 `styles.css` 抽成探针页，容器钉死
`width:354px`，媒体查询条件临时改成 600px（Chrome 窗口最小 500），再 `--screenshot`
对比改前/改后。注意源文件里 `body{opacity:0}` 靠 app.js 打 `data-ready` 才显形，
探针必须强制 `opacity:1`，否则全黑一片以为是布局崩了。

## 默认进入页「偶尔失效」修复（entryPage 机制整体删除）
- 病根：默认进入页没有设置项，全靠「上次停留页」启发式——`MainActivity.onResume` 无条件写 `entryPage=home`、`ComputerListActivity.onResume` 写 `computers`，launcher 冷/暖启动读它，等于 `home` 就不拉列表。用户从列表**按返回**退到电脑页再划走（Android 最自然的退出路径）后，下次必落电脑页 → 用户感知为「默认进列表偶尔失效」。另分屏双 resume 时两处写顺序不定，状态易被污染。
- 修法：launcher 进入（冷启动 + singleTask onNewIntent）**一律** `startActivity(ComputerListActivity)`，`PREF_ENTRY` 常量、两处写入、两处读取全删（两文件 grep entryPage 归零；APK 四个 dex 扫字符串确认无残留）。
- 验证：手机锁屏（指纹）看不到画面，但 `dumpsys activity activities` 冷启动后栈顶 = ComputerListActivity 且 launchedFromPackage=自身，证明自动拉起生效。行为代价：后台时停在电脑页（WebView）再点图标会被送回列表——这正是用户要的「列表=默认进入页」。

## 配对管理「重新出码」（gateway_pair_reissue）
- 用户问题：配对后配对串看不了（扫码失败/手机删了配对就得重新添加）。这是设计使然：落盘只存 SHA-256，明文令牌只在签发瞬间存在 —— 不能改成存明文（破坏「配置拖走也泄露不了令牌」的安全线）。
- 正解 = 换发而非回看：`gateway_pair_reissue(id, tunnel, kind)` 同档案换新令牌（token_sha256 替换、revoked=false、created_at/pair_addr/pair_kind 更新），旧令牌随哈希替换即刻失效 + `websocket_disconnect_all()`；已吊销客户端重新出码 = 复活。手机端按 `(mid,kind)` 幂等顶替，重扫回到原条目，不用重新添加。重构出 `normalize_pair_kind` / `pair_string_for` 与 issue 共用。
- 前端：出码弹窗双模式（`gwPairReissue` 状态 + `gwPairTitle`）——重新出码不填名字、地址类型预选 pair_kind 可改；**改了通道类型手机端会落新槽位**（(mid,kind) 键变了），JS 里 toast 提醒删旧条目。客户端列表在线/已吊销行都加「重新出码」按钮。提示语补「配对串只在生成时显示一次」。
- codegen 资产验证坑：`tauri-codegen-assets/` 里**堆着历次构建的多个 hub.html**（按内容哈希命名），挑第一个像 hub 的会拿到旧版做假阴性 —— 必须枚举全部、用新 ui-version 标记（pair-reissue）匹配。

## iOS 密码保存策略对齐 Android（2026-10-26 晚）

- 诉求：iOS 终端别每次弹「输入 SSH 密码」，密码保存策略与 Android 一致；
  老版那个「只放内存、不落盘」的弹窗等价物要去掉。
- 对齐四条（Android 6786caf 之后的现状）：编辑框存密码默认勾选 / 只在「密码认证 &&
  无可用密码」才弹 / 应急框「保存密码」默认勾选且输一次即落盘 / 落盘失败不静默。
  iOS 新增 `JumpStore.rememberPassword`（逐行对齐 Android 同名方法），
  两处复制粘贴的弹窗合并成 `Servers/ManualPasswordBody.swift` 一份。
- **根因（关键）**：`CODE_SIGNING_ALLOWED=NO` 构建的模拟器包「未签名」，没有任何
  entitlement → 每次 Keychain 调用返回 `-34018 errSecMissingEntitlement`，密码永远存不进去，
  于是每次进终端都弹框。用户装的就是这种包。改法：模拟器构建用 Xcode 默认 ad-hoc 签名
  （`Sign to Run Locally`，不需要 team），**不要**再传 `CODE_SIGNING_ALLOWED=NO`。
  文档 12.2 已改，并新增 12.7 记录整套策略。
- `KeyVault.save` 现在返回 Bool + 失败 NSLog（原来把 OSStatus 丢了，`-34018` 完全隐身）；
  `load` 也记录非 notFound 的异常。
- 顺带修：连接失败时把 Citadel/NIO 英文内部报错直接甩给用户（`...(unknown context at $...)
  Disconnected error 1.)`）。新增 `SshSessionManager.describe(_:)`：先按 `SSHClientError`
  枚举判，再按文本兜底（认证失败/拒绝/超时/不可达/域名解析/未建立），原始信息只进 NSLog。
- 验收：UI 探针 `testSavedPasswordSkipsPrompt` 通过 —— 没存密码弹框、输完保存后重开不再弹。
  调试钩子新增 `-ABSeedSavedPassword=1`（给样例里密码认证那台预写钥匙串）。
