## mac 上编 PC（Tauri）+ Android 的可用配方

本机是 **Hackintosh：AMD Ryzen 7 5700X、macOS x86_64、无 arm64**（`uname -m` = x86_64，
`hw.optional.arm64` 不存在）→ 只能出 x86_64 版；Windows 版仍需 Windows 机（无 MSVC）。

**PC**：`npm run build:mac-intel`（package.json 里已带 `env -u CARGO PATH=$HOME/.cargo/bin:...`
+ clang AR，别自己拼 cargo 命令）。约 1.5 分钟。产物：
- `src-tauri/target/x86_64-apple-darwin/release/anyboot`
- `bundle/macos/AnyBoot.app`（ad-hoc 签名 `-`，`codesign -v` 通过，64M）
- **dmg 这一步在本机会失败**：`bundle_dmg.sh` 要挂载 + AppleScript 让 Finder 摆窗口布局，
  无 GUI 自动化许可时报 `failed to run bundle_dmg.sh`（前面 hdiutil create 是成功的）。
  清场：`hdiutil info` 找残留挂载点（名字是随机 `dmg.xxxxxx`）→ `hdiutil detach -force` →
  删 `macos/rw.*.dmg`；补包：`hdiutil create -volname AnyBoot -srcfolder macos/AnyBoot.app
  -ov -format UDZO dmg/AnyBoot_0.1.0_x64.dmg`（无背景图/布局，能装）。

**前端是否真的进了二进制**（`frontendDist: "../ui"`，Tauri 2 codegen 会 brotli 压缩，
中文搜不到别急着报「没更新」）：看
`target/<triple>/release/build/anyboot-*/out/tauri-codegen-assets/` 里哪个文件 mtime 是新的，
再用 node 的 `zlib.brotliDecompressSync` 解压搜自己的新函数名——比 `strings` 靠谱。

**Android**：无 `gradlew`、无全局 gradle，直接用已下载的 wrapper 发行版：
`~/.gradle/wrapper/dists/gradle-8.14.3-bin/<hash>/gradle-8.14.3/bin/gradle`（AGP 8.7.3 要 Gradle 8.9+）。
必须显式给 JDK17 + SDK + **覆盖 user.home**：
```
env JAVA_HOME=/usr/local/software/jdk/jdk-17 \
    ANDROID_HOME=$HOME/Library/Android/sdk GRADLE_USER_HOME=$HOME/.gradle \
    gradle '-Dorg.gradle.jvmargs=-Xmx2048m -XX:MaxMetaspaceSize=512m -Dfile.encoding=UTF-8 -Duser.home=/Users/jianghh' \
    :app:assembleDebug
```
`gradle.properties` 里写死了 `-Duser.home=/home/jianghh`（Linux 机器），不覆盖的话
debug keystore / `.android` 会去找不存在的目录。产物 `app/build/outputs/apk/debug/app-debug.apk`。

**APK 内容核对**：类不止在 classes.dex（本工程 4 个 dex，`RemotePair` 在 **classes3.dex**），
逐个 dex `unzip -p … | strings | grep` 才搜得到；别用体积当判据。

## 电脑添加/编辑弹窗：flex + 容器查询（commit 721715f）

**根因不是"没写 flex"，是特异性被吃掉**：`.field input`（0,1,1）盖掉 `.rp-timeout{width:62px}`
（0,1,0）→ 通道超时框变整行宽，把 ↑↓ 按钮顶出可视区；`.pb-note{width:84px}` 同理。
修法：基础外观用 `.field :where(input, textarea)` 把特异性降到 (0,1,0)，组件规则才生效。
**但 select 那条只能用 `.field > :where(select)`**：电源路由的 `.route-act/.route-mode` 是
`flex:none` 的窄下拉，被通配会各撑满一行。

**布局**：`.dialog.rs-edit` 改 flex 外壳（head/foot `flex:none`、`.dialog-body` 承担滚动 +
`container-type:inline-size` + `container-name:rsedit`），宽度 `min(600px,100%)`；配对行拆
`.pb-main` / `.pb-meta` 两行，操作件收进 `.pb-act`（`margin-left:auto`）保证 ✕ 不掉行。

**本机可用的界面验证法（mac 没有 CDP）**：
1. node 脚本把 hub.html 的所有 `<style>` + `#rsEditOverlay` 片段抽成独立探针页（`/tmp/rsprobe.js`），
   `hidden` 全去掉、overlay 改 `position:static`，再用假数据摆出 pb-row/bp-row/rp-row；
2. `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome --headless=new --screenshot
   --force-device-scale-factor=2` 截图，肉眼比对；
3. 同一页面注入诊断脚本读 `getComputedStyle` + 逐元素 `getBoundingClientRect().right > 容器右边界`
   数溢出（改前 15 个、改后 0），比看图可靠；
4. **`--window-size` 最小只到 500px**（再小会被夹住：480 请求实测布局 500），要测更窄的弹窗
   就把 `body{width:420px}` 钉死来模拟，别信小窗口截图。
5. 探针要按 CSS 里有没有 `.pb-main` 规则自动选新旧 DOM 形状，否则"改前"截图是假对比。

## 手机界面崩坏排查（commit 3231940，真机 96b199d）

**先纠正一个长期误解**：手机主界面不是原生 Compose，是 **WebView 加载电脑端的
`ui/index.html`**。所以「页签折行 / 橙色横幅错乱 / 底部状态条三行」全都得改 PC 前端
（`ui/styles.css` + `ui/app.js`），改完重编 App 才会生效。只有电脑列表、编辑表单、
抽屉是 Compose。

**视口 354px 是这次的关键数字**：真机 1240px / 3.5 密度 = 354 CSS px，AVD 是 1080/2.625
= 411px —— 411 下刚好放得下的三个页签，354 下就折成「系统引 / 导」。过去只在模拟器上看
所以没发现。720px 断点管不到这么窄，新加 **480px 断点**（只补四条：页签平分 nowrap、
横幅 flex 换行、状态条 line-clamp 2、系统卡片按钮整行铺开）。

**Compose 侧的通用病灶：M3 `TextButton` 有 58dp 最小宽度**。配对行一行三个（↑↓✕）
= 174dp，354dp 屏上地址框只剩 78dp，实测只显示「https」四个字母，地址既看不见也改不了。
解法是自绘 `TinyTextButton`（30dp、无底色），顺带干掉按压态的紫色胶囊残留。同样
58dp 也把通道优先级行的名称挤到折行（「Tailscale Funnel（内建）」）。

**「⏻」(U+23FB) 在 Android 上没有字形** → 主界面悬浮球是个空白紫圆。凡是把 Unicode
符号当图标用都要在真机核一遍；项目 `Icons.kt` 里已有自绘 PowerIcon/CloseIcon。

**验排版的方法**（mac 无 CDP、模拟器太慢）：把 `styles.css` 抽成探针页，容器钉死
`width:354px`，媒体查询条件临时改成 600px（Chrome 窗口最小 500），再 `--screenshot`
对比改前/改后。注意源文件里 `body{opacity:0}` 靠 app.js 打 `data-ready` 才显形，
探针必须强制 `opacity:1`，否则全黑一片以为是布局崩了。

## 超时框可读性（ui-version 20261026-timeout-field）
- 三处超时输入框原来都是「裸 58~66px 数字框 + placeholder『默认』」，无可见标签；窄弹窗里还和来源文字挤在同一行，用户报「看不到字」。
- 引入 `.to-field` 控件组（`超时/默认超时` 标签 + input + `秒`），`rsTimeoutField()` helper 三处复用：`rsPairRow`（pb-meta）、`rsRenderBlockPolicy`（bp-row）、`rsRenderRoutes`（rp-row）。
- 数字框统一 58px / 11.5px / `appearance:textfield` + 隐藏 webkit spinner（原先 spinner 吃掉 14px）。
- 修两个 order 副作用：① `.rp-btn{order:3}` 不限定时把 pb-act 里的 ↑↓✕ 排到启用开关后面（窄弹窗开关跑到最左）；② 只给 to-field/rp-btn 设 order 会让默认 order:0 的 switch 插到名字后 → 三者必须同一档 order:1，`.rp-sub` 用 2。所有 rp-* 选择器都要 `.rp-row > ` 限定，否则溢出到配对行。
- 验证：`/tmp/to_probe.js` 生成 420/620 双宽探针（配对行 + 区块默认超时 + 通道优先级），headless Chrome `--headless=old --force-device-scale-factor=3` 截图。
- codegen 验证法（重要）：`src-tauri/target/<triple>/release/build/anyboot-*/out/tauri-codegen-assets/` 里就是压缩后的资产，**文件名是内容哈希、内容是 brotli**；`zlib.brotliDecompressSync` 解压后 grep 新类名即可确认前端改动进没进包，再拿 `subarray(64,160)` 在二进制里 indexOf 确认链接进去了。
