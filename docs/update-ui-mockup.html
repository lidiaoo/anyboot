E · flex 布局与适配规范（实现硬约定）与本文档 CSS 逐条对应

flex 布局

· 页面/卡片/行/按钮内一律 display:flex，全文档 0 个 float 与 grid 布局； · 横向排列全部走 .row（flex + flex-wrap:wrap + gap + min-width:0）； · 卡片群用 flex:1 1 340px 流式铺排，容器宽自动并排、窄自动换行； · 长内容（更新日志、URL、文件名）容器必须 min-width:0 + overflow-wrap:anywhere； · 行尾元素用 margin-left:auto 弹簧推进（tag、预计剩余时间）。

适配移动端

· 断点 ≤720px：状态卡 flex-basis:100% 转单列（UX-023 P0）； · 按钮转弹性全宽（flex:1 1 auto），触控目标 ≥44px（UX-024 P0）； · 移动端正文 ≥16px 档、按钮 15px 加权重（UX-033 P0）； · 弹窗按钮窄屏纵向排列（column-reverse，主按钮在下=拇指易达）； · 手机端（Compose）与本文档同构：.row→Row、卡片纵排→Column、进度条→LinearProgressIndicator。

适配任何分辨率

· 无固定像素宽容器：外层 width:100% + max-width:1200px 居中； · 字号/间距 clamp() 流体缩放（320px～4K 平滑）； · 弹窗宽度 min(460px, 100%)、手机框 min(340px, 100%)——小屏不超容器； · 验收线：320 / 375 / 768 / 1280 / 2560 五档截图均无横向滚动（P0 阻断项）； · 暗色为默认主题，亮色经 html.light 类切换，全部颜色走变量不硬编码。
