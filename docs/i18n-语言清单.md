# i18n：常见国家 / 地区 ↔ 语言清单

> 用途：确定 AnyBoot 要支持哪些语言。**以「语言」为单位而不是「国家」**——同一语言多国共用（西语 20+ 国），
> 同一国家也可能多语言（瑞士、加拿大、印度、新加坡）。
> Locale 采用 BCP-47：`<语言>-<地区>`。

## 11. AnyBoot 的推荐分层（结合产品定位）

产品是「黑苹果 / 多引导远程管理」，用户集中在 **Hackintosh 社区 + 中文主市场**。
社区活跃度（GitHub/论坛）大致：中、美、德、俄、巴西、越南、印尼、土耳其、日、韩较突出。

| 层级 | 语言 | 理由 |
|---|---|---|
| **Tier 0（首发必备）** | `zh-CN`、`en-US` | 主市场 + 开源默认 |
| **Tier 1（第二批）** | `zh-TW`（+`zh-HK` 共用）、`ja-JP`、`ko-KR`、`de-DE`、`ru-RU`、`pt-BR`、`es-ES` | 社区活跃 + 中文圈完整 |
| **Tier 2（按反馈）** | `fr-FR`、`it-IT`、`nl-NL`、`pl-PL`、`tr-TR`、`vi-VN`、`id-ID`、`th-TH`、`uk-UA`、`es-419` | 增量社区 |
| **Tier 3（谨慎）** | `ar-SA`、`he-IL`、`fa-IR` | **RTL**：现有 CSS 大量 `left/right`，需改逻辑属性（成本高），暂缓 |
| 不建议早期 | 印度各邦语言、非洲小语种 | 投入产出低 |

**建议首批落地 2 语言（zh-CN + en-US），跑通全链路后再按 Tier 1 扩。**

## 12. 关键注意点

1. **中文变体**：`zh-CN`（简）与 `zh-TW`/`zh-HK`（繁）**用词不同**（如「设置/設定」「网络/網路」），不能简单转码，要分别翻译。
2. **葡语变体**：`pt-BR` 与 `pt-PT` 有词汇差异，优先 `pt-BR`（用户量更大）。
3. **西语变体**：用 `es-419` 覆盖拉美，`es-ES` 单独一份。
4. **英语变体**：`en-US` 为基准，`en-GB` 仅少量拼写差异（可后置或复用）。
5. **RTL（阿/希/波）**：需要 UI 镜像（CSS 逻辑属性 `margin-inline` 等）+ 图标方向调整；**当前手写 CSS 成本高，建议 Tier 3 再评估**。
6. **CJK 字体**：Web 端用系统字体栈（`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans CJK"…`），不打包字体（体积）；Android/iOS 系统自带。
7. **语言 ≠ 地区**：`zh-CN` vs `zh-SG` 可复用；`de-DE/AT/CH` 若内容差异小可复用 `de-DE` 包，但**货币/日期格式**按地区。
8. **回落链**：`zh-HK → zh-TW → zh-CN → en-US`；`pt-PT → pt-BR → en-US`。
9. **日期/数字**：一律用 Intl（`n()`/`d()` / `NumberFormat` / `DateFormatter`），不手拼，避免格式错。
10. **不做的事**：不按国家列语言（会爆炸）；不承诺「所有国家」；按社区呼声增补。
