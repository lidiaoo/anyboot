导入流程 S1/D1 主页→ 文件选择→ 口令页（加密文件）→ S3/D5 摘要预览→ S6b/D7 覆盖确认（策略=覆盖时）→ 执行中（进度）→ S4/D6 结果报告

同步流程 S1/D1 开关→ S2/D2 WebDAV 配置→ 测试连接三态（成功 / 404→创建 / 401）→ 立即同步（进行中/失败态）→ S6a 关闭同步确认
