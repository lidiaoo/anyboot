# 备份与恢复 UI 设计规格（PC 桌面端 + 手机端）

依据：`docs/backup-design.md`（v4，功能与数据契约）+ ui-ux-pro-max 引擎推导（产品类型 Developer Tool · 风格 Industrial/Utility · 反模式「light-only」需双主题）。
本文规格**到每一个弹窗、每一个按钮、每一个逻辑操作**。文案逐字以 backup-design.md §6 为准，本文不重复定义。

---

## 0. 设计基线（三端共用语义，各按本端 token 落地）

| 语义 | 手机 iOS（ABColor） | 手机 Android（Theme.kt） | 桌面（CSS vars） |
|---|---|---|---|
| 强调/主按钮 | `.accent`（靛蓝） | accent | `--accent`（#6366f1） |
| 页面底 | `.base` | base | `--bg` |
| 卡片/面板 | `.card` | card | `--surface` |
| 主文字/次文字/弱文字 | `.fg` / `.fgDim` / `.fgFaint` | fg / fgDim / fgFaint | `--text` / `--text-2` / `--text-3` |
| 危险/警示 | 红 `#E5484D` / 黄 `#F5A623` 系警示底 | 同 | `--danger` / `--warning` |
| 成功 | `.ok` 绿 | ok | `--ok` |

通用规范（P0 门禁落到本功能）：
- 触控目标 ≥ 44×44pt（UX-012）；桌面可点元素 ≥ 28×28px。
- 每屏**只有一个主按钮**（UX-028）：导出页=「导出到文件」；导入预览=「导入所选」；口令页=「确认」。
- 永不仅凭颜色表意（UX-003）：成功/失败/警示一律 图标+文字 同现。
- 双主题全量出（浅/深各核一遍对比度 ≥4.5:1）。
- 键盘/读屏：所有输入有 label（UX-007）；弹窗 trapping focus、Esc 可关（桌面）；iOS 用 accessibilityLabel。

**元素与逻辑**

| # | 元素 | 状态与逻辑 |
|---|---|---|
| L1 | 分类行（5 行） | 点整行切换勾选；计数实时；SSH 密钥行勾选→口令区展开(动画 200ms) + 若未开加密则 info 条变黄警示「含私钥的备份必须设置口令加密」+ **主按钮置灰**；取消勾选→恢复。空分类可勾（导出空表），计数显示「（0）」 |
| L2 | 口令两输入框 | 任一非空且≥6 位才允许主按钮；两次不一致→输入框描边 danger + 行内错误 12pt「两次输入不一致」；visibility 图标切换明文 |
| L3 | 导出到文件 | 点击→组包中态（按钮转 loading，文字不变，禁点）→完成弹系统分享面板→toast「已导出 5 类数据（电脑 3 · 服务器 2 · 密钥 1 …）」。KeyVault 读密失败：该条跳过，结果 toast 追加「密钥 1 把读取失败已跳过」 |
| L4 | 启用多端同步开关 | 开→若未配置 WebDAV，自动跳 S2 并 toast「请先配置 WebDAV 服务器和同步内容」；关→确认弹窗（见 S6a）：「关闭后本设备将停止自动同步，已上传的云文件保留」 |
| L5 | WebDAV 与同步内容行 | 副行显示当前服务器 host（12pt fgFaint）；已配置时右侧绿点 |
| L6 | 立即同步行 | 未配置→整行置灰 40% 不可点；配置后可点→行内转圈+「同步中…」，期间离开页面后台继续；完成刷新状态行 |
| L7 | 从文件导入 | 拉起系统文件选择器（iOS `.anyboot`+`.json` 过滤可选「所有文件」兜底）；Android 支持分享/打开方式进本页（onOpenURL/new intent 带文件直接跳 S3 前置流程） |

| # | 元素 | 状态与逻辑 |
|---|---|---|
| L8 | 保存按钮 | 地址非空且含 scheme 才有效；点击→写 KeyVault/prefs→返回 S1 + toast「已保存」；口令区展开但不完整→保存仍可（未启加密时口令忽略） |

### 通用态

- **空态**：分类全空（新装无数据）→S1 各分类计数「（0）」正常可导；导入空备份→S4「该分类在本备份中为空」。
- **加载**：所有 >300ms 的操作必须有行内/按钮内 loading；同步进行中锁重入（L6 置灰）。
- **错误映射**：网络超时/401/404/配额满/文件损坏/版本过高，统一行内或 toast，禁止裸 alert。

## 4. 通用状态机（三端一致）

```
导出: idle → collecting(按钮 loading) → sharing/saved → idle
导入: pick → [decrypt?] → preview → applying(可取消?否) → report
同步: idle → pulling → merging → pushing → idle ｜ 任一步失败→error(带原因,退避)
锁:  同步互斥（进行中禁手动+去抖暂停）；导入/导出与同步互斥（页内提示「正在同步，请稍后」）
```

错误码→文案（统一表，接设计文档 §6）：`401→用户名或密码错误`、`404→远端目录不存在`、`5xx/超时→服务器无响应，请稍后重试`、`quota→WebDAV 空间不足`、`gcm→口令错误或文件已损坏`、`version→备份来自更新版本，请先升级 App`、`size→文件超过 10MB，已拒绝`。

## 5. 交付 QA 门禁（本功能 P0 清单）

- [ ] 每个可点元素有可读名（读屏）；双主题对比度实测 ≥4.5
- [ ] 密码框默认掩码+👁；两次口令一致性行内即时校验
- [ ] 主按钮唯一/屏；危险操作（覆盖导入、关闭同步）二次确认且确认钮红色
- [ ] 所有 loading ≥300ms；同步互斥/防重入；错误永不用裸 alert
- [ ] 手机：单手可达（主按钮底部）；桌面：全键盘可达+焦点环
- [ ] 导出/导入全流程离线可用（WebDAV 功能除外）
